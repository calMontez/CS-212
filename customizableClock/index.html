This site was made when I was still in high school (2021). It is so convoluted to the point where I don't even know how some of these things work. This was written entirely using raw HTML, CSS, and JS with the help of JQuery (yikes) and I still don't think I've topped this project in terms of innovation and sheer ingenuity. I wrote this entire thing on a Chromebook in classes that I should've been paying attention in, and I'm lucky to still have a version of this code. Many aspects of this code make no sense; for example, the math for the automatic scroll speed, which just multiplies the length of the message by 0.07666098807, and the batshit insane style.css full of numbers like 49.6875vw and 0.20833333333333334vw. If I were to remake it today it would be so much better although I still don't know how I got the scrolling message to work so well. It still has a shit ton of issues (like the fact that the textbox parses raw HTML) so don't @ me.
